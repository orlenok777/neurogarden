# НейроСад

Бесплатные графические игры для тренировки внимания и памяти для людей старшего возраста. Личный сад растёт с каждым занятием.

**Сайт:** https://orlenok777.github.io/neurogarden/

10 игр: «Пары в саду», «Найдите отличия», «Цвет и слово», «Тропа чисел», «Садовые колокольчики», «Найдите в саду», «Собери картину», «Маршрут ёжика», «Тёплые связи», «Сад воспоминаний».

Статический сайт (HTML/CSS/JS), работает без интернета, прогресс хранится только на устройстве.

Практика внимания и памяти · Не диагностика и не лечение.
